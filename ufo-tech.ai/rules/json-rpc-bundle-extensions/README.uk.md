# Правила для розширень JsonRpcBundle

Для пакетів, що розширюють [JsonRpcBundle](/docs/api/json-rpc-bundle/developers/extensions): новий транспорт, адаптер протоколу, інтеграція чи інструменти. Використовуйте разом із [правилами для JsonRpcBundle](/ai/rule/json-rpc-bundle).

## Що всередині

* не дублювати ядро: мапа методів, валідація, конвертація параметрів і формат помилок уже є в бандлі;
* точка входу через `RpcExecutor`, перевірка токена, група й версія API для запиту, маршрути через `IApiRouteImport`;
* обмеження для компонентів, що створюються під час компіляції контейнера, і правила для подій;
* вимоги до пакета: версія бандла, структура README і документації, функціональний тест, сумісність у межах мажорної версії.
