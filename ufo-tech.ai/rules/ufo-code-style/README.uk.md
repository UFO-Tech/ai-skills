# Стиль коду UFO-Tech

Необов'язковий стиль коду команди UFO-Tech для PHP-проєктів. Підключайте його лише в проєктах, що приймають цей стиль; якщо у проєкті вже є власні домовленості, агент має дотримуватися їх.

## Що всередині

* `declare(strict_types=1);`, повна типізація аргументів, результатів і властивостей;
* DTO й value objects замість асоціативних масивів, незмінність за замовчуванням;
* тонкі контролери, бізнес-логіка в сервісах, репозиторії лише для доступу до даних;
* ранні повернення, невелика вкладеність і короткі методи.

Файл англійською.
