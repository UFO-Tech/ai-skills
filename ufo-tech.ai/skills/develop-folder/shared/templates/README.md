# .develop

Робоча папка для досліджень і обговорень із Claude. У git не потрапляє (`.git/info/exclude`).

| Шлях | Що там |
|---|---|
| `glossary.md` | терміни й абревіатури, згруповані за темами |
| `investigations/<тема>.md` | дослідження, по файлу на тему чи контекст запиту |
| `questions/open/` | ⚠️ нові питання, ⏸️ відкладені |
| `questions/accepted/` | ✅ прийняті рішення |
| `questions/rejected/` | 🛑 відхилені |
| `issues/features/` | фічі й доробки: `<іконка>-NNN-<назва>.md` |
| `issues/bugfix/` | баги: `<іконка>-NNN-<назва>.md` |
| `docs/` | як працює функціональність зараз, з підпапками за структурою проєкту |

Статуси: ⚠️ нове / чекає рішення · ⏸️ відкладено · ✅ прийнято · 🛑 відхилено · 🏁 реалізовано (тільки задачі).

Задачі готові до Jira: заголовок H1 — це Summary, а все до розділу «Локальні посилання» — Description.
