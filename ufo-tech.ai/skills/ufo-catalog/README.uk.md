# Каталог UFO Tech — пошук і встановлення

Скіл, з якого варто почати: після нього агенту достатньо сказати «знайди в каталозі UFO Tech скіл для …» або «встанови правила json-rpc-bundle в цей проєкт».

## Що робить

1. Читає індекс каталогу `https://ufo-tech.space/ai/catalog.json` — назви, описи, теги, файли й контрольні суми.
2. Шукає за вашим запитом і показує до п'яти варіантів з посиланнями на сторінки.
3. Питає, куди встановлювати: у проєкт (бачить уся команда, якщо закомітити) чи глобально (для всіх ваших проєктів).
4. Показує, які файли й куди запише, завантажує їх і звіряє SHA-256 з індексом.
5. Для правил додає рядок-посилання в `CLAUDE.md` чи `AGENTS.md`, якщо агент цього потребує.

Агент не запускає завантажені скрипти й не змінює глобальні налаштування (hooks, `settings.json`) сам — такі кроки він лише показує вам.

## Як встановити

**Найпростіше** — дайте будь-якому агенту посилання й попросіть виконати:

```text
Прочитай https://ufo-tech.space/ai/install.md і встанови скіл ufo-catalog для себе глобально.
```

**Вручну** — команди для Claude Code і Codex є нижче на цій сторінці, у блоці «Встановлення».

## Оновлення й видалення

Скажіть агенту «онови скіли з каталогу UFO Tech» — він порівняє контрольні суми й завантажить лише змінені файли. Для видалення: «видали скіл … з каталогу UFO Tech».
