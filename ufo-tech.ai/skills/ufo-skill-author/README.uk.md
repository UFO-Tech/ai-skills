# Автор скілів для каталогу UFO Tech

Скіл для тих, хто хоче поділитися своїм скілом чи правилом через цей каталог. Агент знає, як має бути влаштована тека позиції, і збирає її за вас.

## Що робить

* з'ясовує, що це має бути — **скіл** (задача, яку агент виконує сам, коли вона доречна) чи **правило** (інструкції, яких агент дотримується в проєкті завжди);
* створює теку позиції в `ufo-tech.ai/` вашого публічного репозиторію на GitHub: `manifest.yaml` з `vendor/name`, назвою, описом і тегами (англійська обов'язкова, інші мови — за бажанням), `README.en.md` і README іншими мовами;
* робить варіанти для різних агентів (`claude/`, `codex/`, `universal/`) і виносить спільне — скрипти, шаблони, довідку — у `shared/`, щоб нічого не дублювалося;
* пише `SKILL.md` у форматі Agent Skills з описом, за яким агент вирішує, коли скіл потрібен;
* перевіряє результат: маніфест і обов'язкові файли, скрипти, пробне встановлення.

## Як працює

Короткий `SKILL.md` у кожному варіанті посилається на спільний `reference.md` — повну специфікацію каталогу. Цей скіл сам влаштований саме так, тож його можна взяти за зразок.
